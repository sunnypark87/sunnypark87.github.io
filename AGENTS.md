# Repository instructions

Before proposing or implementing changes, read [docs/structure.md](docs/structure.md).
For Git operations, follow [docs/git-conventions.md](docs/git-conventions.md).

- Build the content authoring and deployment structure first; redesign the design system afterward.
- Preserve the distinction between agreed direction, pending decisions, and implemented behavior.
- Do not automatically carry previous designs into the renewal as established standards.
- Read [docs/brand-guidelines.md](docs/brand-guidelines.md) for brand principles before UI changes; undecided layouts and components remain undecided.
